The assignment focuses on the following major topics:

- Definition of IPv4 addresses and their uniqueness requirements
- Flat vs. hierarchical addressing
- Static vs. dynamic IP addressing
- Classful vs. classless addressing and CIDR
- IPv4 configuration parameters for Internet access
- Classful address classification
- Network and broadcast analysis
- Practical troubleshooting of invalid gateway configuration
- DHCP recommendations for small lab networks
